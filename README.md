# 3D Theater

MMD 系のモデルを使って 3D アニメーションを作る、Windows 用のソフト。
何を作るかは [開発指示書](3D_Theater_開発資料一式/3D_Theater_開発指示書.md) にまとめてある。

## 今の状態（Phase 3 の 6 段階目まで：物理演算・物理の焼き込み・音声・グラフエディタ・モーフの拡張・元に戻すの検証）

Phase 3 で新しくできたこと:

- 元に戻す・やり直しの検証: でたらめな編集を続けてから全部戻す・全部やり直すと、各時点の状態にぴったり戻ることを確かめるテストを足した。見つかった 2 つの点（自動キーを途中で切り替えたときのまとめ方、ボーンの回転のごくわずかなずれ）を直した
- 「モーフ」パネル: 行の ◆ で今のフレームにキーを登録、未登録の変更を「まとめて登録」。表情のプリセット（一覧に出ているモーフの値に名前を付けて保存。どのモデルでも名前の合うモーフに当たる）と、プリセットを割合で混ぜて当てる（すぐ当たり、元に戻せる）
- PMX 2.1 のフリップモーフ（値で 1 つを選んで切り替える）とインパルスモーフ（物理演算が ON のとき剛体を押す・止める）が効くようになった

- グラフエディタ（「グラフ」パネル）: 選んだボーン・モーフ・カメラの値の変化を線で見せ、キーの補間曲線を MMD と同じ 0〜127 の枠で変える（点のドラッグ・数の入力・線形／なめらか／加速／減速／段階のボタン。元に戻せる）。キーを選んでいなければ、今のフレームのキーの曲線を変える

- 音声: WAV・MP3 などの曲を読み込み（ファイルメニュー、ドラッグ）、再生に合わせて鳴らす。再生中は鳴っている位置に合わせてフレームを進めるので、映像と音がずれていかない。タイムラインに波形を出す。鳴り始めのフレーム・音量を変えられ、シーン一覧の目の印で音を消せる。読み込み・外すは元に戻せ、プロジェクトに保存する

- 物理の焼き込み: 0 フレーム目から順に計算した物理の結果を、画面の手が空いたときに作って覚えておく。再生位置をどう動かしても、同じフレームなら同じ姿勢になる。キーや姿勢を変えると作り直す（状態表示に「物理を計算中 n / N」）
- 物理演算（Bullet）: PMX の剛体とジョイントで、髪・スカート・飾りなどが重力と動きに合わせて揺れる。止まっているときに姿勢を変えると、2 秒ほど揺れて落ち着く
- 物理の ON / OFF（モデルメニュー、ツールバーの「物理」。プロジェクトに保存）と「物理をリセット」

Phase 2 でできたこと（PMX・ボーンとモーフ・モーション・元に戻す・キーの編集・プロジェクトの保存・ギズモ・カメラのモーション・描画の土台）:

- GPU が使えなくなったとき（ドライバーの更新など）は、自動で作り直して描画を続ける。ヘルプ「GPU を作り直す」でも同じことができる
- フレームの速さを変えるとき、キーの位置も合わせて動きの秒数を保つかを選べる（元に戻せる）
- シーンのカメラの初期位置を MMD と同じにした（人の大きさのモデルの全身が収まる）
- 状態表示の描画の時間にマウスを乗せると、内訳（変形・描画の依頼・GPU 待ち・表示）が出る

- カメラのモーション: VMD のカメラのキーを読み込んで再生し（カメラ視点の区画で見る）、カメラのキーの登録・編集・書き出しもできる。MMD と同じく注視点・回転・距離・視野角で補間する
- モデルをシーンから外す（モデルメニュー、Delete）。外す操作もモデルの読み込みも元に戻せる

- ギズモ: プレビューで取っ手をドラッグして、ボーン・モデル・カメラなどを動かす・回す。MMD 方式（移動の矢印と回転の輪を一緒に出す）と Blender 方式（選んだ道具の取っ手だけ）を切り替えられ、ワールド／ローカルの座標、Ctrl でスナップ、ドラッグ中の右クリック・Esc で取り消し。ドラッグ 1 回が 1 つの「元に戻す」

- プロジェクトの保存と読み込み（`.3dtproj`）。新規・開く・保存・名前を付けて保存。モデルは場所だけを保存し（原本は書き換えない）、キー・姿勢・未登録の変更・カメラなどを保存する。見つからないモデルは知らせ、保存し直しても消さない
- 保存していない変更があれば題名に「＊」を付け、閉じる・新規・開くの前に保存するか尋ねる。2 分ごとの自動保存と、保存せずに終わったときの復旧
- モーション（VMD）とポーズ（VPD）の書き出し

- 元に戻す/やり直し（Ctrl+Z / Ctrl+Y）。値の変更・名前・表示・ロック・キーの登録と破棄・モーションとポーズの読み込み・キーの編集を戻せる。つまみのドラッグなど続けた変更は 1 回分にまとめる
- タイムラインでキーを編集: クリック・範囲選択で選び、ドラッグで移動（Ctrl+ドラッグで複製）、Delete で削除、Ctrl+C / Ctrl+V でコピーと貼り付け、右クリックで補間（線形・なめらか・段階）

- モーション（VMD）とポーズ（VPD）の読み込み。今操作しているモデルに当てはめる（名前の対応は MMD と同じ。合わないボーン・モーフはレポートで知らせる）
- キーフレームで動く: 再生・フレーム移動に合わせてボーンとモーフが動く。補間はベジェ曲線（MMD と同じ 4 本）・線形・段階
- タイムラインにキーを◆で表示。「キーを登録」（I）で選んだボーン・モーフを今のフレームのキーにする
- 自動キーフレーム（初期値は OFF）。OFF のときに手で動かした値は「未登録の変更」として残し、フレームを動かしても捨てない。タイムラインの上の「すべて登録」「破棄」で決める

- ボーンとモーフでモデルを動かせる: FK・IK（ひざの角度制限つき）・付与・軸固定・変形階層、BDEF1/2/4・SDEF の変形、頂点・UV・ボーン・材質・グループモーフ
- シーン一覧にボーン（表示枠ごと）と表情（目・まゆ・口・その他）が並ぶ。選んだボーンの移動・回転、モーフの値をプロパティ欄で変えられる
- 「モーフ」パネル: 今操作しているモデルのモーフを分類と名前で絞り込み、つまみで動かす（キーの登録・プリセット・混ぜるは Phase 3 で足した）
- 選んだモデルのボーンをプレビューに線で重ねる（色で種類が分かる。プレビューのボタンで切り替え）。線の近くをクリックするとボーンを選ぶ
- 「ポーズを初期化」でボーンとモーフをすべて戻す

- PMX 2.0 / 2.1 の読み込み（頂点・面・材質・ボーン・IK・モーフ・表示枠・剛体・ジョイント）。元のファイルは書き換えない
- 読み込みレポート: 範囲外の参照・見つからないテクスチャ・未対応の要素（PMX 2.1 のソフトボディなど）を一覧で知らせる。内容はコピーできる
- 読み込んだモデルを全プレビューに表示（テクスチャ・半透明・両面描画・簡単な陰影）。何体でも置け、位置・回転・拡大・表示切り替えが反映される
- テクスチャは PNG・BMP・JPG・DDS・TGA などを読む
- プレビューのクリックでモデルを選べる（選択中は囲む箱を強調）。最初のモデルを読み込むと、各区画がそのモデルに合わせて寄る
- 読み込み方: メニュー「ファイル → モデルを読み込む」（Ctrl+I）・「モーション・ポーズを読み込む」、ウィンドウへのドラッグ、起動時の引数

**ギズモの拡大、IK の切り替えのキー、照明のキーはまだ**で、必要に応じて作る。トゥーン・輪郭線・影は Phase 4。

Phase 1 までにできていること:

- タイトルバーに入れたメニュー（11 項目）と、その下の独立したツールバー
- Visual Studio 型のドッキング画面（タブ化・フローティング・自動非表示・複数モニター・閉じる/再表示）
- レイアウトの保存と復元、「初期配置に戻す」。知らないパネルが入ったレイアウトでも起動できる
- プレビュー（何枚でも追加可）。中を 1・2・4 画面に分けられ、4 画面の組み合わせは 3 通りから選べる
- 正面・背面・右側面・左側面・上面・下面の固定視点（平行投影）、自由視点（透視投影）、カメラ視点
- 視点の操作: 中ボタンドラッグ = 回転、Shift + 中ボタンドラッグ = 平行移動、ホイール = ズーム、区画ごとの最大化
- シーン一覧（検索・表示切替・編集ロック・名前変更・複数選択）、プロパティ（位置・回転・拡大、カメラの視野角など）
- タイムラインの最小構成（目盛り・再生位置・再生/停止・1 フレーム移動・ループ・24/30/60 fps）
- プレビュー・シーン一覧・タイムライン・プロパティの選択の連動と、全プレビューが同じフレームを表示すること
- ログのパネル

まだできていないこと（「予定」と書いたメニューやボタンは押せない）:

- ギズモの拡大、IK の切り替えのキー、照明のキー
- PMD（古い形式）の読み込み（後日）
- 物理の床との当たり、陰影のある描画と書き出し（Phase 4）、プラグイン（Phase 5）
- 操作感度・ショートカットの設定画面、区画の境目のドラッグでの大きさ変更

モデルを読み込めるまでは、確認用の立方体で表示と操作を確かめる（再生位置に合わせて回る）。

## 必要なもの

- Windows 11（x64）
- Visual Studio 2026（Community 可）に次の 2 つを入れたもの
  - 「C++ によるデスクトップ開発」
  - 「.NET デスクトップ開発」
- .NET 10 SDK（Visual Studio と一緒に入る）

## ビルドとテスト

PowerShell でこのフォルダーを開いて実行する。

```powershell
.\build.ps1
```

- `-Configuration Release` で Release ビルド
- `-SkipTests` でテストを飛ばす
- `-Run` でビルドのあとアプリを起動する

スクリプトの実行が止められる場合は次のようにする。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Visual Studio で開く場合は `3DTheater.slnx` を開き、`3DTheater.App` をスタートアップにして実行する。
C++ のコードも続けてデバッグできるよう設定してある。

> C++ のプロジェクトを含むため、`dotnet build` ではビルドできない。`build.ps1` か Visual Studio を使う。
> 最初のビルドでは物理演算の Bullet（`external/bullet3`）もビルドするため、30 秒ほど長くかかる。

## 起動

```text
src\3DTheater.App\bin\x64\Debug\net10.0-windows\3DTheater.exe
```

| オプション | 意味 |
|---|---|
| `--warp` | GPU を使わないソフトウェア描画で起動する（診断用） |
| `--debug-layer` | Release でも Direct3D の検査機能を使う（Debug では常に使う） |
| PMX ファイルのパス | 起動したあとに、そのモデルを読み込む（いくつでも並べられる） |
| VMD / VPD ファイルのパス | モデルを読み込んだ後に、そのモーション・ポーズを当てはめる |
| プロジェクト（.3dtproj）のパス | そのプロジェクトを開く |

GPU での初期化に失敗したときは、自動でソフトウェア描画に切り替えて起動する。
GPU の面を WPF と共有できない環境では、描いた絵を読み出して表示する方式に自動で切り替える（状態表示に「読み出し方式」と出る）。

## 操作

| 操作 | 動き |
|---|---|
| 中ボタンでドラッグ | 視点を回す（固定視点からは自由視点へ移る） |
| Shift + 中ボタンでドラッグ | 視点を平行に動かす |
| ホイール | 拡大・縮小 |
| 左クリック | 選ぶ（Ctrl で追加・解除）。ボーンの線の近くならボーンを選ぶ |
| ダブルクリック / Num . | 選んだ物に合わせる |
| 右クリック | 視点のメニュー |
| Num1 / Ctrl+Num1 | 正面 / 背面 |
| Num3 / Ctrl+Num3 | 右側面 / 左側面（Blender と同じ向き） |
| Num7 / Ctrl+Num7 | 上面 / 下面 |
| Num0 / Num5 | カメラ視点 / 透視と平行の切り替え |
| Space | 再生・一時停止 |
| ← / → | 1 フレーム移動 |
| Home / End | 先頭 / 末尾（プレビューの上では Home = 視点を初期状態に） |
| Ctrl+A / Esc | すべて選択 / 選択を解除 |
| Ctrl+N / Ctrl+O | 新しいプロジェクト / プロジェクトを開く |
| Ctrl+S / Ctrl+Shift+S | 保存 / 名前を付けて保存 |
| Ctrl+I | モデル（PMX）を読み込む（ウィンドウへのドラッグでも読み込める） |
| I | 選んだボーン・モーフを今のフレームのキーにする |
| ギズモの取っ手を左ドラッグ | 動かす・回す（Ctrl でスナップ、ドラッグ中の右クリック / Esc で取り消し） |
| Q / W / E | 道具: 選択 / 移動 / 回転（Blender 方式に切り替わる） |
| Delete（キーを選んでいないとき） | 選んだモデルをシーンから外す（Ctrl+Z で戻せる） |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す / やり直し |
| Delete / Ctrl+C / Ctrl+V | タイムラインで選んだキーを削除 / コピー / 今のフレームに貼り付け |

タイムラインでは、キーをクリックで選び（Ctrl で追加・解除）、帯の空いている所からのドラッグで範囲選択、選んだキーのドラッグで移動（Ctrl を押しながらで複製）、右クリックで補間などのメニュー。再生位置は上の目盛りのドラッグか、帯の空いている所のクリックで動かす。

## 設定とログの置き場所

| 内容 | 場所 |
|---|---|
| レイアウト・プレビューの分け方・ウィンドウの位置 | `%APPDATA%\3DTheater\UserSettings\` |
| ログ | `%LOCALAPPDATA%\3DTheater\Logs\`（メニュー「ヘルプ → ログフォルダーを開く」） |
| 自動保存 | `%LOCALAPPDATA%\3DTheater\AutoSave\`（保存せずに終わったとき、次に起動すると復旧するか尋ねる） |

レイアウトがおかしくなったときは、ツールバーの「初期配置」を押すか、`UserSettings` フォルダーを消して起動し直す。
