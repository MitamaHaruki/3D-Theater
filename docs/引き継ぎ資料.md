# 3D Theater 引き継ぎ資料（OS の入れ直しのため・2026-11-25）

開発している PC の Windows を入れ直すときのための資料です。入れ直す前にすること、入れ直した後の用意、今の作業の続き方をまとめました。
細かい決まりと経緯は `docs/設計判断記録.md`（1〜100 章）、使い方は `README.md` にあります。

## 0. 入れ直す前に（大事な順）

1. **プッシュしていないコミットを、GitHub へプッシュする。**
   - 2026-11-25 の時点で、手元の `master` は GitHub（`MitamaHaruki/3D-Theater` の `main`）より 9 個進んでいる（`ba9f7cc`〜`e48c6b5`。3D Theater VCamera の 1〜3 段目と、その記録）。
   - プッシュの仕方（GitHub CLI のログインを、その場だけ使う）:

     ```powershell
     git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push origin master:main
     ```

   - 確かめ方: `git status` が「Your branch is up to date」、`git log --oneline origin/main..master` が空になればよい。
2. **ディスクの分かれ方を守る。** 入れ直すのは C:（SSD。ディスク 0）だけにする。D: と E: は消さない。
   - D:（HDD。ディスク 1）: このリポジトリ（`D:\活動\Apps\3D Theater`）・ドキュメント（`D:\Users\<名前>\Documents`。3D Theater のシーン）・MMD のモデル（`D:\MMD`）・Dropbox（`D:\Dropbox`）。
   - E:（SSD。ディスク 2）: Visual Studio（`E:\Visual Studio\Community`）。入れ直した後は、Visual Studio を入れ直す（下の 2）。
   - **ドライブの文字（D:・E:）を変えない。** シーン（`.3dtlive`）は、モデルを `D:\MMD\…` のような決まった場所で覚えている。
3. **C: にあって消える物の控え**を、Dropbox の `開発\3D Theater の引き継ぎ（2026-11-25）` に写した（中身は下の 5）。Claude の覚え書き・Claude と 3D Theater の設定・確かめの道具・git に入っていない試しの物。
4. git に入れない物は、そのまま D: に残る（消さない・コミットしない）:
   - リポジトリの直下の `動画 2026-11-13 19 58 31.mov`・`ライブモードUIサンプル.png`・`YYB式鏡音レンv1.00_キー.csv`。
   - `artifacts\`（ビルドの生成物と、試しの物 `vrm-samples`・`fbx-samples`・`ps-samples`・`motion-samples`）。試しの物は控えにも写した。
   - Dropbox の `開発\3D Theater\3D Theater VCameraテスト用動画.mp4`（利用者の確かめ用の動画。リポジトリに入れない。写した画面に映像を残さない）。

## 1. 今どこまでできているか

- 3D Theater: MMD のモデルを動かす Windows のアプリ（WPF・.NET 10 と、C++ の Direct3D 11 の描画エンジン）。エディットモード（作品づくり）とライブモード（配信）がある。できることは `README.md` の「今の状態」。
- 3D Theater VCamera（付属のアプリ）: ほかの PC（今はノートパソコン）のカメラで顔・手・体を読み、結果だけを VMC プロトコルで 3D Theater へ送る。5 段の計画（98 章）のうち、3 段目まで作った。
  - 1 段目（顔・98 章）・2 段目（手と指・99 章）は、ノートパソコンで確かめ済み。2 段目は、手を横に向けたとき・指先をカメラへ向けたときに、指の震えが少し残る。
  - 3 段目（腕と上半身・手首・100 章）は、ノートパソコンで「腕がとても震える」「位置によっては逆側が動く」と分かったので、直した（`e48c6b5`）。
- **今の作業: 3 段目の直しの、ノートパソコンでの確かめ待ち。** ARM64 の zip（`3DTheater-確かめ用-0.1.0-ARM64-20261122-2300.zip`）と指示書（`Claude への指示書.md`）を、Dropbox の `開発\3D Theater` に置いてある。
  - 利用者がノートパソコンで確かめたら、Claude に「ノートパソコンで確認できたので確認して」と頼む。Claude は、Dropbox のメモ（`確かめのメモ_日付.md`）とログの zip、この PC の 3D Theater のログ（`[腕]` の行。腕の骨の揺れ）を読み、100 章に書く。
  - まだ震えるなら、ノートパソコンのカメラの動画を撮ってもらうのがよい（こちらで同じことを起こして直せる）。
- この後の候補（設計判断記録 80 章「持ち越し事項」の表に全部ある）:
  - VCamera: 横向きの指の震え（99 章）・4 段目（相手を自動で見つける・ほかのアプリ向けの腕と指のボーン・Windows の起動と一緒に・省電力）・5 段目（任意。NPU で軽くする）・有線（ノートパソコンの LAN の変換が見つからない）。
  - ARM64 の版の描画の「つかえ」（94 章）。
  - 配布の用意（署名・インストーラー）は、頼まれるまで触らない。

### ビルドとテスト

PowerShell でリポジトリのフォルダーを開き、`.\build.ps1` を流す（ビルドとテスト。2026-11-25 の時点で C++ 59・C# 635 のテストが全部通る）。

- `.\build.ps1 -Configuration Release`: 速い版。
- `.\package.ps1 -Platform ARM64`: ノートパソコン向けの確かめ用の zip（`artifacts\package` にできる）。
- C++ のプロジェクトがあるので、`dotnet build` では全体をビルドできない（`build.ps1` か Visual Studio を使う）。
- 初めのビルドは、物理演算の Bullet（`external/bullet3`）も作るので、少し長くかかる。

### Windows の設定（入れ直すと元に戻るもの）

- **ドキュメントの場所**: 前は `D:\Users\<名前>\Documents` に移してあった。同じ場所へ移し直す（エクスプローラーで「ドキュメント」の「プロパティ」→「場所」）。3D Theater のライブモードのシーンは「ドキュメント\3D Theater\シーン」にある（「部屋」など）。
- **ファイアウォール**: 3D Theater で VMC プロトコルを初めて受け取るとき、Windows の確認が出る。「プライベート ネットワーク」で「許可」を押す（押さないと、ノートパソコンから届かない）。
- **仮想カメラ**: 前は登録してあった（`C:\Program Files\3D Theater\VirtualCamera`）。使うなら、3D Theater の設定画面の「配信」→「仮想カメラを使う」で入れ直す（管理者の確認が出る）。
- ファイルの関連付け（`.3dtproj`・`.3dtlive`）は、登録していなかった。

### 3D Theater の設定とログ

- 設定（`%APPDATA%\3DTheater\UserSettings`。並び・窓の位置・描画品質など）は、控えに写した。戻すなら、同じ場所へ写す（無くても、初めの設定で起動する）。
- ログ（`%LOCALAPPDATA%\3DTheater\Logs`）・自動保存は、控えに写していない（無くてよい）。

### Python の環境（モデルの変換と確かめの道具）

一時フォルダー（`%TEMP%`）に作ると、Windows の片付けでファイルが消えて壊れる（2026-11-22 に起きた）。リポジトリの外の、消えない場所に作る。

```powershell
py -3.10 -m venv D:\作業\venv_pose
D:\作業\venv_pose\Scripts\pip install "tensorflow==2.15.1" "numpy<2" "tf2onnx==1.17.0" "onnx==1.16.2" "onnxruntime==1.19.2" "mediapipe==0.10.21" "opencv-python<4.12"
```

- モデルの変換: `tools\convert_face_models.py`・`tools\convert_hand_models.py`・`tools\convert_pose_models.py`（使い方は、それぞれの先頭に書いてある）。変換したモデルは `models\` に入っている（作り直さなくてよい）。
- `mediapipe`・`opencv-python` は、確かめの道具（MediaPipe 本体と答えを比べる・動画を読む）にだけ使う。

## 3. Claude（開発を手伝う AI）の引き継ぎ

### 覚え書き（メモリー）を戻す

Claude は、このプロジェクトの覚え書きを `%USERPROFILE%\.claude\projects\D-----Apps-3D-Theater\memory\` に置いている（フォルダーの名前は、リポジトリの場所 `D:\活動\Apps\3D Theater` から決まる。リポジトリの場所を変えない）。入れ直すと消えるので、控えに写した。

1. Claude Code を入れて、ログインする。
2. 控えの `claude\memory\` の中身（`MEMORY.md` と 21 個の `.md`）を、`%USERPROFILE%\.claude\projects\D-----Apps-3D-Theater\memory\` へ写す（フォルダーが無ければ作る）。
3. 控えの `claude\CLAUDE.md` を `%USERPROFILE%\.claude\CLAUDE.md` へ写す（「やり取りは全部日本語で、専門用語を使わずに」という、全部のプロジェクトに効く決まり）。
4. 控えの `claude\settings.json` を `%USERPROFILE%\.claude\settings.json` へ写す（別のプロジェクトの自動モードの説明が入っている。無くても困らない）。
5. Claude Code で `D:\活動\Apps\3D Theater` を開き、「docs/引き継ぎ資料.md を読んで、続きを進めて」と頼む。

### Claude が守っている決まり（覚え書きにもある）

- やり取り・コミットの説明は、全部日本語。専門用語を避ける。
- コミットの名前は「Mitama Haruki」と GitHub の noreply のメール（覚え書きの `git-identity.md`）。プッシュは頼まれたときだけ（`github-push.md`）。
- 「次を進めて」と頼まれ、前の段がコミットしていなければ、先にコミットする。
- アプリを起動して確かめるときは:
  - 直前に `UserSettings` を控え、終わったら戻す。
  - 窓はモニター 2（右上の画面）に出す。
  - `--scene-folder=` で、利用者のシーンに触れない。
  - 本物のマウスは動かさない。画面の部品は、アプリの窓の中だけで探す。
  - 写した画面は、使い終わったら消す。
- 利用者の確かめ用の動画は、点を結んだ線を黒い背景に描くほかは、画面に出さない・残さない。
- 確かめ用の zip は `artifacts\package` に作り、zip と指示書だけを Dropbox へ写す（`-OutDir` を Dropbox にしない）。
- 配布の用意・LICENSE は、頼まれるまで触らない。
- 個人の情報（家の IP・メールなど）を、コミットするファイルに書かない。

### 確かめの道具（一時フォルダーにあったもの）

Claude の作業用の一時フォルダーは、入れ直すと消えるので、よく使った物を控えの `確かめの道具\` に写した。中の道具は、前の一時フォルダーの場所（`$sp`）を書き込んであるので、使うときは場所を書き換える。

| ファイル | 何をするか |
|---|---|
| `project_flow.ps1` | 画面の確かめの共通の関数（起動してモニター 2 へ出す・窓を写す・設定を控えて戻す など） |
| `body_flow.ps1` | 本アプリと VCamera を同時に動かし、確かめ用の動画で腕・指が動くかを見る（3 段目の確かめ。前半に、これまでの確かめの関数が入っている） |
| `toon_check\settings.json` | 画面の確かめのときに使う、決まった 3D Theater の設定 |
| `poseprobe\` | 確かめ用の動画を読んで、体と手のトラッキングと腕の当てはめに通し、腕の骨の回転を CSV に書く（`laptop` を渡すと、ノートパソコンに近い形にして読む） |
| `pose_tools\analyze_aims.py` ほか | その CSV の揺れを数える・点を結んだ線を黒い背景に描く・MediaPipe 本体と比べる |
| `peek_arms\`・`peek_bones\` | PMX のボーンの並びと位置を書き出す |
| `tocrlf.py` | ファイルの改行を CRLF にそろえる（作業用のファイルの改行を、ほかのファイルに合わせる） |

## 4. ノートパソコン（確かめ用）

- Surface（Snapdragon X2 Elite・ARM64。Windows 11）。確かめ用の ARM64 の zip を、Dropbox から受け取って動かす。この PC の入れ直しの影響は受けない。
- やり方: この PC で zip と `Claude への指示書.md` を Dropbox の `開発\3D Theater` に置く → ノートパソコンの Claude が指示書の通りに確かめ、メモ（`確かめのメモ_日付.md`）とログの zip を同じ所に置く → この PC の Claude が読んで記録する。
- VCamera の確かめでは、ノートパソコンからこの PC の 3D Theater へ、家の Wi-Fi で送る。この PC の IP は、3D Theater のトラッキング情報の状態の行に出る（入れ直して変わったら、ノートパソコンの Claude に伝える）。
