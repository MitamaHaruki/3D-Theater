# ライセンス一覧

3D Theater が使っている外部の部品と、その利用条件。部品を足したら必ずここに追記する。
採用前に「配布の形・ライセンス・保守状況・Windows での互換性」を確かめること（開発指示書 9.1）。

## アプリと一緒に動くもの

| 部品 | 版 | 用途 | ライセンス | 配布 |
|---|---|---|---|---|
| .NET 10 ランタイム（WPF を含む） | 10.0 | 画面と C# のコード全体 | MIT | 今は同梱しない。利用者が「.NET デスクトップ ランタイム 10」を入れる |
| Dirkster.AvalonDock | 4.74.1 | ドッキング画面 | Ms-PL | アプリの出力に DLL が入る |
| Dirkster.AvalonDock.Themes.VS2013 | 4.74.1 | ドッキング画面の暗い配色 | Ms-PL | アプリの出力に DLL が入る |
| Microsoft Visual C++ 実行時ライブラリ | — | C++ エンジンの実行 | Visual Studio の再頒布条件 | 今は同梱しない。「VC++ 再頒布可能パッケージ」が要る |
| Direct3D 11 / DXGI / Direct3D 9Ex | — | 3D の描画 | Windows の一部 | Windows に含まれる |
| DirectXMath | — | 行列・ベクトルの計算 | MIT（Windows SDK に同梱） | ヘッダーだけ。コードに組み込まれる |
| Segoe Fluent Icons / Segoe MDL2 Assets | — | ボタンのアイコン | Windows の一部 | 同梱しない（OS の書体を使う） |

### Ms-PL（AvalonDock）を配るときの注意

- 配布物に含まれる著作権表示などを消さないこと（Ms-PL 3(C)）。
- AvalonDock をソースのまま配る場合は Ms-PL の全文を付けること（3(D)）。今は DLL（コンパイル済み）だけを配る形で、その場合は Ms-PL と矛盾しない利用条件で配ればよい。
- 配布の形を決めるときに、ライセンス全文（NuGet パッケージ内の `LICENSE`）を配布物に添えることを推奨する。

## 素材について

- `3D_Theater_開発資料一式/references/` の参考画像は画面配置の参考で、アプリには入れない。画像の中のキャラクターや素材は使わない。
- アプリのアイコンはコードで描いている（画像ファイルは使っていない）。
- 検証用のモデル・モーションは、利用条件がはっきりしたものだけを `samples/` に置く（開発指示書 9.2）。
