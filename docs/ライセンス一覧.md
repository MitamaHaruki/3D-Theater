# ライセンス一覧

3D Theater が使っている外部の部品と、その利用条件。部品を足したら必ずここに追記する。
採用前に「配布の形・ライセンス・保守状況・Windows での互換性」を確かめること（開発指示書 9.1）。

## アプリと一緒に動くもの

| 部品 | 用途 | ライセンス | 配布 |
|---|---|---|---|
| .NET 10 ランタイム（WPF を含む） | 画面と C# のコード全体 | MIT | 今は同梱しない。利用者が「.NET デスクトップ ランタイム 10」を入れる |
| Microsoft Visual C++ 実行時ライブラリ | C++ エンジンの実行 | Visual Studio の再頒布条件 | 今は同梱しない。「VC++ 再頒布可能パッケージ」が要る |
| Direct3D 11 / DXGI / Direct3D 9Ex | 3D の描画 | Windows の一部 | Windows に含まれる |
| DirectXMath | 行列・ベクトルの計算 | MIT（Windows SDK に同梱） | ヘッダーだけ。コードに組み込まれる |

## 開発・テストだけで使うもの（配布しない）

| 部品 | 用途 | ライセンス |
|---|---|---|
| MSTest 4.0.2 | C# のテスト | MIT |
| Microsoft C++ 単体テスト フレームワーク | C++ のテスト | Visual Studio に付属 |
| Visual Studio Community 2026 | 開発環境 | Visual Studio Community の利用条件（個人・小規模なら可。組織で使う場合は条件を確認） |

## 採用を検討中のもの（まだ使っていない）

| 部品 | 用途 | ライセンス | 状態 |
|---|---|---|---|
| Dirkster.AvalonDock | ドッキング画面 | Ms-PL | Phase 1 で検証 |
| Bullet Physics | 物理演算 | zlib | Phase 3 で検証。MMD と同じ揺れ方になる版を調べる |

## 素材について

- `3D_Theater_開発資料一式/references/` の参考画像は画面配置の参考で、アプリには入れない。画像の中のキャラクターや素材は使わない。
- 検証用のモデル・モーションは、利用条件がはっきりしたものだけを `samples/` に置く（開発指示書 9.2）。
